# Changelog

## 0.2.0

- Move the Flutter facade into `packages/noosphere_flutter`, with separate demo
  and native integration-host applications.
- Depend on the renamed `noosphere_protocol` package at `^0.2.0`.
- Upgrade Frosty to 5.0.1 and the Iroh packages to 1.1.0.

## 0.1.2

- Added an opt-in public event feed with a durable journal, signed checkpoints,
  and a separate unauthenticated polling client.

## 0.1.0

- Initial release.
